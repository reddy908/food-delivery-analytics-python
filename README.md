# 🍔 Food Delivery Delay & Restaurant Performance Analytics

## 📌 Overview

This project analyzes food delivery data using Python to identify
factors associated with delivery delays and evaluate restaurant
performance.

## 🎯 Objectives

- Analyze delivery performance
- Identify delayed orders
- Investigate factors affecting delivery time
- Compare restaurant performance
- Analyze traffic and weather impact
- Identify high-risk delivery conditions
- Generate business recommendations

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🔍 Analysis

- Data Cleaning
- Missing Value Treatment
- Duplicate Detection
- Outlier Detection using IQR
- Exploratory Data Analysis
- Correlation Analysis
- Restaurant Analysis
- Traffic Analysis
- Distance Analysis
- Weather Analysis
- Cuisine Analysis
- Area Analysis
